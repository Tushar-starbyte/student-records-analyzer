# Student Records and Marks Analyzer (Module 3 Mini-Project)

A terminal-based Python application that uses core data structures (Lists, Tuples, Sets, and Dictionaries) to store, process, and analyze student records.

## Features
- **Tuple**: Holds fixed subject names (`Python`, `Maths`, `DBMS`).
- **Dictionary**: Maps student IDs to nested student details.
- **List**: Stores subject marks for dynamic calculations and supports indexing/slicing.
- **Set**: Extracts unique subject collections.

## How to Run
```bash
python main.py
